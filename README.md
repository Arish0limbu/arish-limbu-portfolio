## Development

Clone the repository:

```bash
git clone https://github.com/Arish0limbu/Arish0limbu.github.io.git
cd Arish0limbu.github.io
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Deployment

The portfolio is designed for GitHub Pages and uses a static production build. No backend server or database is required.
